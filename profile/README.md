# Lineage OS Revived

A fork of LineageOS with the goal to simplify building older versions and adding in some small features.
Also includes misc fixes and perfomance improvements from [crDroid](https://github.com/crdroidandroid), some privacy enhancements from [Divest OS](https://github.com/Divested-Mobile/DivestOS-Build/tree/master/Patches)

Currently the following branches are supported and tested:
- lineage-20.0
- lineage-19.1
- lineage-18.1
- lineage-17.1
- cm-14.1
